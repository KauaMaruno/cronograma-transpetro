PUBLICAÇÃO PELO GITHUB WEB:
1. Baixe e extraia o ZIP.
2. No repositório GitHub, abra Add file > Upload files.
3. Envie o conteúdo da pasta (index.html, assets/, sw.js, manifest.webmanifest e README.md), substituindo os arquivos existentes.
4. Faça Commit changes.
5. Abra o site e atualize com hard refresh (Ctrl+Shift+R / Cmd+Shift+R).

IMPORTANTE: não apague nem substitua as configurações do projeto Supabase. A chave pública existente foi mantida no app.js.
